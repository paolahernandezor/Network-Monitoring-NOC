
## Network Monitoring & Financial Risk Dashboard (NOC)

Este proyecto simula un **Centro de Operaciones de Red (NOC)** que integra la generación de telemetría en tiempo real con análisis de impacto financiero.

##  Características Principales
*   **Backend dinámico:** Script en **Node.js** que genera métricas aleatorias de CPU, latencia y estado de dispositivos.
*   **Visualización Avanzada:** Dashboard en **Power BI** con gráficos de burbujas dinámicos y eje de reproducción temporal.
*   **Lógica de Negocio:** Clasificación de estados (*Critical, Healthy, Warning*) y cálculo automático de **Costo de Riesgo** basado en fallas críticas.

## Tecnologías 
*   **Lenguaje:** JavaScript (Node.js) para la lógica de datos.
*   **Visualización:** Power BI Desktop para el reporte analítico.
*   **Control de Versiones:** Git y GitHub para la gestión del portafolio profesional.

## Impacto del Proyecto
El tablero permite identificar proactivamente qué dispositivos están en riesgo y traduce fallas técnicas a un valor monetario, facilitando la toma de decisiones para un **Analista de Proyectos**.
